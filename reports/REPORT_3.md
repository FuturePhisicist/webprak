# Третий отчет

## Web-интерфейс

Реализованы страницы Thymeleaf для основных вариантов использования:

* главная страница с переходами к служащим, подразделениям, должностям и графу подразделений;
* список служащих с поиском по ФИО, фильтрами по подразделению и должности, сортировкой;
* карточка служащего, форма добавления/редактирования, история назначений, форма назначения/перевода;
* список и карточка подразделения, форма добавления/редактирования, представление иерархии подразделений;
* список и карточка должности, форма добавления/редактирования.

## Сценарии системного тестирования

1. Главная страница открывается и содержит переходы ко всем ключевым разделам.
2. Поиск служащего по существующему ФИО возвращает найденную запись.
3. Поиск служащего по отсутствующему ФИО возвращает сообщение об отсутствии данных.
4. Запрос карточки отсутствующего служащего возвращает страницу ошибки 404 с конкретным сообщением.
5. Добавление служащего с корректными данными завершается редиректом на карточку новой записи.
6. Добавление служащего с ошибкой валидации возвращает форму и сообщение конкретного типа.
7. Удаление служащего с активным назначением возвращает бизнес-ошибку.
8. Назначение на занятую ставку возвращает бизнес-ошибку о нехватке свободных ставок.
9. Карточки подразделения и должности открываются и показывают данные из тестовой базы.
